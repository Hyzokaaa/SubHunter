// Features

BUILT FOR PRECISION

SubHunter uses video file hashing to find the exact subtitle for your release. No more timing issues. No more wrong versions.

01
Hash-based matching
Computes a unique hash of your video file to find the subtitle that syncs perfectly with your exact release.
02
Provider picker
Shows all available subtitles from every provider with match scores. You choose which one to download.
03
Auto-fallback
If a provider fails, SubHunter automatically tries the next best option. No manual intervention needed.
04
11 languages
Spanish, English, Portuguese, French, Italian, German, Chinese, Japanese, Korean, Arabic, and Russian.
05
Auto-update
Notifies you when a new version is available and updates itself automatically. Always stay current.
06
Dark & Light modes
Cinematic dark theme with golden accents by default. Switch to light mode when you prefer it.
OpenSubtitles.com OpenSubtitles.org Subtitulamos.tv Addic7ed Gestdown Podnapisi TVSubtitles

// How it works

THREE STEPS. THAT'S IT.

1
Load your videos
Drop a folder or select individual files. SubHunter detects all video formats automatically.
2
Pick your subtitles
SubHunter searches all providers and shows you every available option with quality scores.
3
Download
One click. The subtitle is saved next to your video, perfectly named for any media player.
